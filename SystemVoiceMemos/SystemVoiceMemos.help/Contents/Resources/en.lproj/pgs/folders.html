Organize recordings in folders

Use folders to group related recordings while keeping every recording available in All Recordings.

Create a folder

  1. Click the add button in the sidebar, or choose File > New Folder.
  2. Enter a folder name.
  3. Press Return.

Move recordings into a folder

  • Drag recordings onto a folder in the sidebar.
  • Control-click a recording and choose Move to Folder.
  • Select multiple recordings, then move them together.

View a folder

  • Click All Recordings to see every recording.
  • Click a folder name to show only recordings in that folder.
  • Choose View > Toggle Sidebar if the sidebar is hidden.

Rename or delete a folder

  1. Control-click the folder in the sidebar.
  2. Choose Rename or Delete Folder.
  3. Confirm the change if macOS asks.
Important: Deleting a folder removes the folder but keeps the recordings. The recordings remain in All Recordings.
