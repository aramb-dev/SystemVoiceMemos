Set up System Voice Memos

Before recording, choose the audio sources you want and grant any permissions macOS asks for.

Before you begin

  • Use macOS 14 or later.
  • Use Microphone permission only if you want to record a mic track.
  • Use Screen Recording permission only if you turn on the Legacy Screen Sharing Engine in Settings.
  • Use Location permission only if you want recordings named with your city.

Grant permissions

The Welcome Guide opens the first time you launch the app. You can also open it later from the Help menu.

  1. Click Grant next to the permission you want to enable.
  2. If macOS opens System Settings, turn on System Voice Memos in the permission list.
  3. Quit and reopen System Voice Memos if macOS says the change requires it.
Note: The default system-audio recorder does not take screen video. The legacy engine uses Apple's screen capture API for audio only.

Make your first recording

  1. Choose File > New Recording, or press Cmd+N.
  2. Play audio on your Mac.
  3. Click Stop Recording when you are done.
  4. Select the new recording in the list to play it or export it.
Important: If another app is capturing system audio at the same time, recording may fail or make your Mac slower.

Find your recordings

Recordings appear in the list after they are saved. To reveal a file in Finder, Control-click a recording and choose Show in Finder.
