Record system audio

You can record system audio by itself, record a microphone as a separate track, or save both sources in one recording.

Start and stop recording

  1. Choose File > New Recording, or press Cmd+N.
  2. Use the recording toolbar or main window to see that recording is active.
  3. Choose File > Stop Recording, press Cmd+N again, or click Stop Recording.

When recording stops, System Voice Memos saves the audio and adds it to the recordings list.

Choose what to record

Use the toolbar or Settings to decide whether to record system audio, microphone audio, or both.

  • System audio: Captures audio playing on your Mac.
  • Microphone: Captures the selected input device as a separate track.
  • No source selected: Recording controls stay available, but the app shows an empty-source state instead of starting an unusable recording.

Record a microphone separately

  1. Open System Voice Memos > Settings > Recording.
  2. Turn on Record Microphone.
  3. Choose whether exports should keep the microphone separate or include it with system audio.

During playback, use the track selector to hear both tracks, system audio only, or microphone only.

Use the legacy engine

The default recorder uses the system-audio engine. If you need the older behavior, turn on Use the Legacy Screen Sharing Engine in Recording settings.

  • The legacy engine captures screen audio through Apple's screen capture API.
  • It does not save screen video or screenshots.
  • It may slow your Mac, especially if other apps are also using the screen capture API or if your Mac has less headroom.

Export separate tracks

  1. Select a recording that includes a microphone track.
  2. Choose the export command from the File menu or the recording shortcut menu.
  3. Choose whether to export the combined audio or separate system and microphone files.

If recording does not start

  • Turn on at least one recording source.
  • Quit other apps that may be capturing system audio.
  • If you use the legacy engine, confirm Screen Recording permission in System Settings.
  • If you record a microphone, confirm Microphone permission in System Settings.
