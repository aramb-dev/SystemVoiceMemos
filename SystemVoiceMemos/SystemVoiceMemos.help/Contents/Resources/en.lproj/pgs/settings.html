Change recording and toolbar settings

Use Settings to choose recording sources, update behavior, naming, and how the recording toolbar appears.

Open Settings

  • Choose System Voice Memos > Settings.
  • Press Cmd+,.

Change recording sources

In the Recording pane, choose the sources and export behavior you want.

  • Record System Audio: Capture audio playing on your Mac.
  • Record Microphone: Save microphone audio as a separate track.
  • Export: Export tracks separately or together when a recording has both sources.
Note: If no recording source is selected, the app keeps the interface available but does not start an unusable recording.

Use the legacy screen sharing engine

Turn on Use the Legacy Screen Sharing Engine only if you need the older screen-capture-based audio path.

  • The legacy engine captures screen audio through Apple's screen capture API without saving video.
  • It requires Screen Recording permission.
  • It may slow your Mac, especially if other apps are using the screen capture API or if your Mac has less performance headroom.

Customize the recording toolbar

In the Toolbar pane, choose how the floating toolbar behaves while recording.

  • Show or hide the floating recording toolbar.
  • Minimize the main window automatically when recording starts.
  • Restore the toolbar if the app window is minimized during recording.

To bring the toolbar back manually, choose View > Show Recording Toolbar while a recording is active.

Change naming and updates

  • Use the General pane to enable city-based names for new recordings.
  • Use the Updates pane to check for new versions and change automatic update behavior.

If a setting does not work

  • Quit and reopen System Voice Memos after changing macOS privacy permissions.
  • Check that the related source is enabled before recording.
  • Turn off the legacy engine if your Mac becomes slow during recording.
